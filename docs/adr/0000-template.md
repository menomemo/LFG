## Context

The forces at play: technical, product, cost, time, legal. What is true right now that
makes this decision necessary, and what constraints are not negotiable. Write this so that
someone who knows nothing about the project can follow why there is a decision to make at
all.

State facts, not the conclusion. If the context only supports one option, the context is
being written backwards from the answer.

## Decision

> We will …

One paragraph, active voice, present tense. Specific enough to be checkable against the
codebase.
